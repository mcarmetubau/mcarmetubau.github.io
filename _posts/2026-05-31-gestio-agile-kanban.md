# 📊 Projecte: Disseny i Implementació d’una Base de Dades amb Metodologia Agile

## 🎯 Objectius del projecte

L’objectiu del projecte és dissenyar i implementar una base de dades relacional treballant amb metodologia Agile i utilitzant un tauler Kanban gestionat amb **Jira**.

Al final del projecte, tots els membres de l’equip hauran participat en totes les fases del desenvolupament:

- Anàlisi de requisits  
- Disseny conceptual (model E/R)  
- Disseny lògic  
- Creació de taules SQL  
- Definició de claus i relacions  
- Inserció de dades de prova  
- Validació i documentació

## 👥 Organització dels equips

- Equips de **3 o 4 alumnes**
- Cada equip selecciona **un projecte diferent**
- Tots els membres han de rotar pels diferents rols Agile

## ⚙️ Metodologia Agile

### 📌 Kanban (Jira)

Cada equip utilitzarà **Jira** amb les següents columnes:

- Backlog
- To Do
- Doing
- Review
- Done

### 🧾 Requisits de les tasques

Tota tasca ha d’incloure:

- Responsable
- Data d’inici
- Data de finalització
- Evidència del treball (captura, document, SQL, etc.)

---

## 👨‍💼 Rols de l’equip

Els rols roten a cada Sprint. Exemple de rols comuns en projectes agiles

### 🧭 Scrum Master
- Coordina reunions
- Actualitza Kanban a Jira
- Detecta bloquejos

### 🔎 Analista
- Defineix requisits
- Revisa coherència del model amb el negoci

### 🧱 Dissenyador de BD
- Dissenya model E/R
- Defineix claus primàries i foranes

### 💻 Desenvolupador SQL
- Implementa taules
- Escriu scripts SQL

---

## 🔁 Registre de rotació de rols

Cada Sprint s’ha d’omplir una taula com aquesta:

| Alumne | Sprint 1 | Sprint 2 | Sprint 3 | Sprint 4 |
|--------|----------|----------|----------|----------|
| Alumne A | Scrum Master | Desenvolupador | Analista | Dissenyador |
| Alumne B | Analista | Scrum Master | Desenvolupador | Analista |

---

## 🗓️ Planificació de Sprints (pensant en un projecte de BD,adaptable a qualsevol exemple)

### Sprint 1 — Anàlisi
**Objectiu:** entendre el problema

Tasques:
- Identificar requisits
- Definir entitats
- Llistar atributs
- Esborrany del model E/R

---

### Sprint 2 — Disseny
**Objectiu:** estructurar la BD

Tasques:
- Definir relacions
- Claus primàries i foranes
- Normalització bàsica
- Revisió entre companys

---

### Sprint 3 — Implementació SQL
**Objectiu:** crear la base de dades

Tasques:
- Crear scripts SQL
- Definir restriccions
- Provar creació de taules

---

### Sprint 4 — Dades i validació
**Objectiu:** finalitzar el sistema

Tasques:
- Inserir dades de prova
- Fer consultes SQL
- Corregir errors
- Documentació final

---

## 🧪 Exemple de microtasques

### 📚 Biblioteca — Taula Llibres

- Definir atributs
- Definir clau primària
- Crear script SQL
- Revisar script
- Inserir dades de prova

### 🔗 Relacions

- Crear relació Autor-Llibre
- Validar integritat referencial
- Generar dades de prova
- Revisar model

### 🧾 Validació

- Executar script complet
- Detectar errors
- Documentar incidències

---

## 🗣️ Reunió diària (Daily Scrum)

Durada: **5 minuts màxim**

Cada membre respon:

1. Què he fet des de l’última reunió?
2. Què faré avui?
3. Tinc algun impediment?

👉 El Scrum Master registra els acords.

##  Evidències obligatòries

Cada equip haurà d’entregar:

- Captura del Kanban final (Jira)
- Historial de tasques
- Model E/R
- Scripts SQL
- Dades de prova
- Registre de rotació de rols
- Informe final breu

---

## 🧮 Criteris d’avaluació

### 🧱 Disseny de base de dades (40%)
- Entitats correctes
- Relacions adequades
- Normalització bàsica

### 💻 SQL (25%)
- Taules correctes
- Claus primàries i foranes
- Integritat referencial

### 📌 Agile i Kanban (20%)
- Ús correcte de Jira
- Seguiment de tasques
- Participació en reunions

### 🤝 Treball en equip (15%)
- Rotació de rols
- Repartiment equilibrat
- Participació de tots els membres

---

## ⭐ Avaluació entre alumnes (rúbrica)

Cada alumne avaluarà els companys amb aquesta rúbrica:

| Criteri | 1 | 2 | 3 | 4 |
|--------|---|---|---|---|
| Participació | Baixa | Mitjana | Alta | Excel·lent |
| Responsabilitat | No compleix | Parcial | Compleix | Supera expectatives |
| Col·laboració | Escassa | Acceptable | Bona | Excel·lent |
| Qualitat del treball | Baixa | Mitjana | Bona | Molt alta |

###  Ponderació final:
- Mitjana de les puntuacions dels companys: **10% de la nota final (opcional per professor)**
